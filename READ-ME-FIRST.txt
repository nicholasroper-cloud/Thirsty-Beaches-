THIRSTY BEACHES — KIOSK (portable / run-from-drive)
====================================================

This folder is SELF-CONTAINED. Nothing needs to be installed on the kiosk PC —
Node is bundled (node.exe) and the server has no dependencies.

WHAT'S IN HERE
--------------
  Run-Kiosk.bat          <- double-click this to START the kiosk
  Stop-Kiosk.bat         <- double-click this to STOP the kiosk (closes Edge + server)
  node.exe               <- bundled Node runtime (don't delete)
  clover-menu-server.js  <- the local server (holds the Clover token, makes orders)
  drink-kiosk.html       <- the kiosk screen
  drink-kiosk-light.html <- same screen (backup copy)
  drink-image-prompts.md <- copy-paste prompts to generate real drink photos
  kiosk-config.env       <- your Clover token + merchant ID  (KEEP PRIVATE)
  assets\                <- logo + any drink photos (assets\drinks\)

HOW TO RUN IT (on the kiosk PC, Windows 10/11)
----------------------------------------------
  1. Copy this whole folder onto the kiosk PC (or run it straight from the USB
     drive — either works).
  2. Set the screen to PORTRAIT:
       Settings > System > Display > Orientation > "Portrait".
  3. Double-click  Run-Kiosk.bat
       - a small server window opens (minimized in the taskbar)
       - Microsoft Edge opens FULL-SCREEN on the kiosk
  That's it.

TO EXIT / STOP THE KIOSK
------------------------
  - Quickest: press  Ctrl + Alt + Delete  (or  Alt + F4 ) to leave full-screen,
    then double-click  Stop-Kiosk.bat  to shut down Edge + the server.
  - Or just close the minimized "Thirsty Beaches Server" window in the taskbar.

CAMERA ("Match My Vibe")
------------------------
  The launcher tells Edge to auto-allow the camera, so the Vibe Reader works
  with no popup. One quick photo is taken to match a drink; it is NOT saved.

  TWO MODES:
   - Default (no setup): the match is done ON THE PC, fully private, no photo
     ever leaves the machine. Fun, but it's a guess.
   - REAL AI matching (optional): paste an Anthropic API key into
     kiosk-config.env (ANTHROPIC_API_KEY=...). Get one at console.anthropic.com.
     Then the photo is sent to Anthropic's AI to pick the drink and is NOT
     stored. Speed/quality: VIBE_MODEL=claude-haiku-4-5 is fast (recommended);
     set VIBE_MODEL=claude-opus-4-8 for the smartest match (slower). Each scan
     costs a small amount of Anthropic API usage.
     IMPORTANT: with AI on, customer photos leave the PC. Before using this in
     public (kids will use it), post a camera notice and have it reviewed for
     privacy/COPPA compliance. If unsure, leave the key blank (private mode).

START AUTOMATICALLY WHEN THE PC TURNS ON (optional)
---------------------------------------------------
  1. Copy this folder to the PC, e.g.  C:\ThirstyBeaches\
  2. Press  Win + R , type  shell:startup , press Enter.
  3. Right-drag  Run-Kiosk.bat  into that Startup folder > "Create shortcuts here".
  Now it launches every time the PC logs in. (Set the PC to auto-login to a
  limited user for a true unattended kiosk.)

ORDERS
------
  Orders placed on the kiosk are created as OPEN ORDERS in your Clover account
  and show up on your Flex / Station so staff can take payment. Internet is
  required (the server talks to api.clover.com).

IMPORTANT — KEEP THIS DRIVE/FOLDER SECURE
-----------------------------------------
  kiosk-config.env contains your Clover API token. Anyone with this folder can use it.
  - Don't share the drive or post the files anywhere.
  - If the drive is ever lost, rotate the token in your Clover dashboard
    (Settings > API Tokens) and drop the new value into kiosk-config.env.

ADD REAL DRINK PHOTOS (makes it look top-tier)
----------------------------------------------
  The cards currently show clean drawn icons. To upgrade to real photos:
  1. Open  drink-image-prompts.md  (in this folder).
  2. Pick ONE image generator (Midjourney, DALL-E, etc.) and generate the whole
     set in one sitting, reusing one seed/style so they all match.
  3. Save each image as  assets\drinks\<id>.png  using the EXACT id listed in the
     prompts file (e.g. Sandy Bottom -> assets\drinks\beached-whale.png).
  4. Refresh the kiosk. Any drink with a photo shows it full-bleed; any without
     keeps its drawn icon. A half-finished photo set still looks intentional.
  No code changes needed - the kiosk auto-detects the files.

UPDATING THE MENU OR LOGO LATER
-------------------------------
  - Replace drink-kiosk.html (and drink-kiosk-light.html) with newer copies.
  - The logo is  assets\logo.png .

TROUBLESHOOTING
---------------
  - Edge didn't open: make sure Microsoft Edge is installed (it ships with
    Windows). Then re-run Run-Kiosk.bat.
  - "Couldn't send" when ordering: check the PC's internet connection.
  - Nothing happens: open the minimized server window to read any error message.
